# EDDALA NITHIN — React Portfolio

A React/Vite portfolio based on the Refero Twingate style reference supplied by the user.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
npm run preview
```

## Notes
- Navigation uses React Router for same-site view/page transitions.
- Resume is included at `public/EDDALA_NITHIN_Resume.pdf`.
- ElectroCart GitHub is intentionally shown as Coming Soon until the user provides the URL.
- Replace the ElectroCart Live Demo placeholder with the actual live URL when available.
- The contact form is UI-only until connected to a backend/email service.
- Project screenshots can be added later without changing the page structure.
